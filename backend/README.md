# سامانه مدیریت هوشمند مدرسه دانا — بک‌اند لاراول (Laravel 12 + MySQL)

بک‌اند جامع، ماژولار، امن و استاندارد مبتنی بر فریم‌ورک **Laravel 12** و پایگاه داده **MySQL 8+** با معماری REST API و احراز هویت **Laravel Sanctum**.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

1. **مدل‌سازی کامل و حرفه‌ای داده‌ها (ORM & Relational Integrity):**
   - جدول کاربران متمرکز با نقش‌های اختصاصی (`admin`، `teacher`، `student`).
   - پرونده کامل دانش‌آموزان و دبیران همراه با کد ملی، کدهای پرسنلی و دانش‌آموزی یکتا.
   - کلاس‌های درس، پایه‌ها، رشته‌های تحصیلی، سال‌های تحصیلی و انتساب چند به چند دروس.
   - ثبت دقیق نمرات با بازه ۰ تا ۲۰، ضرایب دروس، ماه‌های تحصیلی و انواع ارزیابی.
   - دفتر الکترونیکی حضور و غیاب کلاسی (حاضر، غایب، موجه، تاخیر).
   - سامانه مدیریت تکالیف و بارگذاری فایل‌های ارسالی دانش‌آموزان و نمره‌دهی دبیران.
   - موتور هوشمند پردازش و صدور دسته‌جمعی کارنامه‌های ماهانه و ترمیک همراه با محاسبه خودکار معدل و رتبه در کلاس.
   - سیستم غیرقابل تغییر لاگ رویدادها (`AuditLog`) جهت حسابرسی امنیتی کلیه عملیات حساس.

2. **احراز هویت و مجوزها (Authentication & RBAC):**
   - احراز هویت با استفاده از **Laravel Sanctum Token**.
   - میدل‌ویر اختصاصی اعتبارسنجی نقش‌ها (`EnsureUserRole`).
   - ایزولاسیون کامل داده‌های دانش‌آموزان (عدم دسترسی به نمرات و کارنامه دیگران).
   - بررسی دقیق انتساب‌های کلاس و درس برای دبیران قبل از ثبت نمره یا حضور و غیاب.

3. **حساب‌های کاربری اولیه در محیط توسعه (Default Seeded Accounts):**
   - پس از اجرای `php artisan migrate --seed`، حساب‌های زیر به صورت پیش‌فرض در دیتابیس ایجاد می‌شوند:
     - **مدیر (Admin):** نام کاربری `admin` | رمز عبور `1234`
     - **دبیر (Teacher):** نام کاربری `2222222222` | رمز عبور `1234`
     - **دانش‌آموز (Student):** نام کاربری `1111111111` | رمز عبور `123`

## 🛠️ پیش‌نیازها و راه‌اندازی (Setup & Installation)

### ۱. نصب وابستگی‌ها
```bash
cd backend
composer install
```

### ۲. تنظیم متغیرهای محیطی
فایل `.env.example` را به `.env` کپی نمایید:
```bash
copy .env.example .env     # در ویندوز
# یا cp .env.example .env  # در لینوکس / مک
php artisan key:generate
```

تنظیمات پایگاه داده MySQL خود را در فایل `.env` وارد کنید:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=dana_school_db
DB_USERNAME=root
DB_PASSWORD=
```

### ۳. اجرای مایگریشن‌ها و سیدر پیش‌فرض
```bash
php artisan migrate --seed
```

### ۴. اجرای سرور توسعه لاراول (روی پورت 8001)
```bash
php artisan serve --port=8001
```

### ۵. اجرای تست‌های خودکار (Automated Tests)
```bash
php artisan test
```
